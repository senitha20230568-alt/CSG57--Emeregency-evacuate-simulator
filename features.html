EVACSIM Features

Discover the main features of EVACSIM and how they work together to turn building floor plans into interactive environments for emergency evacuation practice.

AI Floor-Plan Recognition

Users can upload a 2D floor plan of a building to begin creating a virtual environment. AI-assisted image recognition analyses the uploaded plan to identify important building elements, including walls, rooms, doors and windows. The recognised information is then organised into structured data that can be processed by the system and used for 3D building generation.

This feature reduces the need to manually recreate the entire building layout and provides the starting point for the evacuation simulation. Users can review the recognition output and make corrections to the generated building in the next stage if necessary.

3D Building Generation

After the AI-assisted recognition stage, the identified building elements are processed and organised into structured data. This information is passed to Unreal Engine, where the system uses predefined 3D assets and components to construct a virtual version of the building. Elements such as walls, doors, windows and rooms are positioned according to the recognised floor-plan layout.

The result is a 3D building environment that users can view and explore before starting an evacuation simulation. This approach focuses on generating the environment from the uploaded floor plan rather than asking AI to create the 3D models themselves.

3D Building Inspection and Editing

After the 3D building has been generated, users can inspect the environment to check whether it accurately represents the uploaded floor plan. This allows them to identify recognition or layout mistakes before running an evacuation simulation.

If changes are needed, users can make corrections to building elements using the available editing tools. Possible actions include adding, moving or deleting walls and doors. Reviewing and correcting the building helps ensure that the virtual environment is suitable for the intended evacuation scenario.

Emergency Scenario Configuration

Before starting a simulation, users can configure an emergency scenario to define the conditions they want to practise. The scenario setup can include selecting an emergency type, such as a fire, and choosing where the hazard begins within the generated building.

Users can also configure scenario settings such as the difficulty level and the number of occupants involved. These options allow different evacuation situations to be prepared and practised within the virtual environment.

Evacuation Simulation

Once the building and emergency scenario are configured, users can start an evacuation simulation inside the generated 3D environment. The user can experience the building layout and practise moving towards available exits while the selected emergency conditions are active.

The simulation uses predefined movement behaviour and physics for the player and non-player characters (NPCs). NPCs represent other building occupants and allow users to observe how an evacuation may unfold with multiple people in the environment. This provides an interactive way to practise evacuation procedures under different scenario settings.

Simulation Results and Performance

After a simulation is completed, users can review a summary of the evacuation outcome. The results can include the total evacuation time and the number of occupants who successfully reached safety. These measurements help users understand how the evacuation progressed under the selected scenario conditions.

By reviewing the results, users can identify areas where the evacuation process may need improvement. They can then adjust the building setup or scenario settings and run another simulation to compare the outcomes. This makes it possible to evaluate different evacuation approaches in a repeatable virtual environment.
