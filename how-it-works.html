How EVACSIM Works

Discover how EVACSIM transforms a 2D building floor plan into an interactive 3D emergency evacuation simulation.

Step 1: Upload a Floor Plan

Users begin by selecting and uploading a 2D floor plan of the building they want to simulate. The uploaded plan provides the layout information needed to create the virtual environment.

For the best recognition results, users should provide a clear and readable floor plan that shows the building layout and its main structural elements. Once uploaded, the plan is ready for the AI recognition stage.

Step 2: AI Floor-Plan Recognition

The AI analyses the uploaded floor plan and identifies key building elements, including walls, rooms, doors and windows. It interprets the layout and converts the recognised elements into structured information that can be processed by the system.

The recognition output is used in the next stages to help create the building layout in 3D. Because automated recognition may not be perfect, users can review the recognised layout and correct any mistakes before continuing.

Step 3: Review and Correct the Building Layout

Before generating the 3D building, users can inspect the layout produced by the AI. They can check whether the recognised rooms and structural elements match the original floor plan.

If an element has been missed or identified incorrectly, users can make corrections to the layout. This review stage helps improve the accuracy of the building representation before it is used in the evacuation simulation.

Step 4: Generate the 3D Building

After the layout has been reviewed, the processed floor-plan information is sent to Unreal Engine 5. The system uses this structured information to position predefined 3D components, such as walls, floors, doors and other building elements.

This process creates a 3D representation of the uploaded building layout. The AI recognises and organises the floor-plan information, while Unreal Engine is responsible for generating the 3D environment.

Step 5: Configure an Emergency Scenario

Once the 3D building is ready, users can configure the emergency scenario they want to practise. They can select the type of emergency, such as a fire, and specify where the hazard begins within the building.

Users can also adjust available simulation settings, such as the difficulty and the number of occupants. These settings define the conditions for the evacuation exercise before it begins.

Step 6: Run the Evacuation Simulation

When the user starts the simulation, the emergency scenario takes place inside the generated 3D building. The user can experience the environment while occupants follow predefined movement behaviour and available evacuation routes.

The simulation represents the selected hazards, such as fire, and allows users to observe how the emergency affects movement through the building. This provides an opportunity to practise evacuation decisions in a controlled virtual environment.

Step 7: View Results and Performance

When the simulation ends, users can review a summary of the evacuation performance. The results include the total evacuation time and the number of occupants who successfully reached safety.

These measurements help users understand how the evacuation scenario unfolded and identify areas that may need improvement. Users can use the results to review their performance and compare different attempts under the same scenario conditions.
