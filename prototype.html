About the Prototype

The EVACSIM prototype demonstrates the proposed user interface and the main workflow of the application. It shows how users can move through the key stages of the system, including uploading a floor plan, reviewing AI recognition results, inspecting the 3D building, configuring an emergency scenario and viewing simulation results.

The prototype is designed to communicate the planned user experience and show how the main screens are connected. Users can navigate between the screens to understand the intended workflow.

Prototype Scope

This is a high-fidelity prototype that demonstrates the proposed EVACSIM interface, screen layouts and user journey. It is intended to show how users may interact with the planned system before full implementation.

The prototype does not perform the actual AI floor-plan recognition, generate a functional 3D building in Unreal Engine or run a live evacuation simulation. These capabilities are part of the proposed system and are not fully implemented in this prototype.
